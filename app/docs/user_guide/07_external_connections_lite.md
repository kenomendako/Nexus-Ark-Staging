# 外部接続とNexus Ark Lite

外部接続は、Nexus Arkをスマホ、SNS、Bot、自作ツールへ広げるための設定です。
中央「外部接続」タブにまとまっています。

## Twitter (X)

中央「外部接続」→「Twitter (X)」で、Twitter投稿の下書き、承認、投稿履歴を扱います。
投稿は下書きキューに入り、人間が承認するまで外部へ投稿されません。
画像生成付き下書きや、投稿履歴の確認にも対応します。

「承認待ち」で「承認待ちを更新」を押すと、最新の下書きから順に表示されます。確認したい行を
選ぶと投稿内容と添付画像が読み込まれ、内容を確認・編集してから承認または却下できます。
バックグラウンドで作られた下書きは自動更新されないため、通知やペルソナの報告を受けた後は
この更新ボタンを押してください。

DiscordからTwitter下書きを承認する場合は、Discord側の許可ユーザーID設定が必要です。

## Discord / LINE

中央「外部接続」→「Discord / LINE」で、Discord BotとLINE Botを設定します。

Discord Botでは、ルームごとのBot割り当て、スラッシュコマンド、ルーム切替、再生成、Twitter下書き承認などを扱います。
LINE Botでは、LINEからペルソナと会話できます。
外部からアクセスする場合は、Cloudflare Tunnel、Tailscale Funnel、ngrokなどのHTTPS URLが必要になることがあります。

## 拡張ツール

中央「外部接続」→「拡張ツール」では、ローカルプラグインとMCPを管理します。

- 「ローカルプラグイン」: Pythonファイルとして自作ツールを追加します。
- 「MCP」: stdio、sse、streamable_http、simple_httpの接続を登録できます。

拡張ツールは便利ですが、外部コマンドや外部サービスへつながる場合があります。
有効化するプラグインやMCPサーバは、内容を理解してから使ってください。

## Nexus Ark Lite・お出かけ

中央「外部接続」→「Lite・お出かけ」は、Nexus Ark Liteとお出かけ機能の共通入口です。
Nexus Ark Liteは、スマホやタブレットのブラウザから使えるインストール対応Webアプリ（PWA）です。
「外部接続」を開いた直後は、左端の「Twitter (X)」が表示されます。Liteやお出かけ機能を使う時だけ
同じ列の「Lite・お出かけ」を選んでください。
このページ上部の「📱 Nexus Ark Lite」「📤 外部AIへ持ち出す」「🏠 外部AIから帰宅」で、
ページを増やさず表示内容だけを切り替えます。スマホ向けNexus Ark Liteの設定と日常操作も
「📱 Nexus Ark Lite」から選びます。REST APIの詳細、外部ツールの説明、
イベントテスターは、別の「API・外部ツール」ページにあります。
最初に「Nexus Ark Liteを使い始める」を開き、使い方を選びます。

- **「PCをつけたまま使う」**: 本体と同じ会話・記憶・機能を使います。ボタンを押すと「本体接続の設定」が開きます。
- **「PCを止めても使う」**: 持ち出したペルソナと必要な記憶で会話し、帰宅後にLiteでの会話を本体へ戻します。
  ボタンを押すと「PCを止めても使うための初回設定」が開きます。

初回設定では、画面に表示された案内に沿って準備確認、AIサービスとモデル、スマホ登録、お出かけの準備へ進みます。
詳しい利用条件は **「PCを止めても使う」の詳しい説明** から確認できます。

Bは、準備済みの方が「Lite用クラウドを接続・確認」から接続します。初めての方は自分のCloudflareアカウント、
新規アカウントでの公式Dashboardによる`workers.dev`初回登録と公開名の入力1回が必要です。Liteの準備ツールはNexus Arkに同梱され、完全なURLは本体が自動で組み立てます。
その後は、保存領域などを準備する確認とインターネットへ公開する確認を分けたウィザードで進みます。
資源IDや秘密のキーを転記する必要はありません。

新規作成は段階提供です。実環境での開放確認が済んでいない配布版では、初回準備ボタンが安全停止し、
Cloudflareを変更しません。その場合は本体接続を使い、Nexus Arkの更新後に再確認してください。
詳細は **「PCを止めても使う」の詳しい説明** で確認できます。準備済みの資源は従来どおり接続できます。

### 一つのページ内での切り替え

「外部接続」→「Lite・お出かけ」が正面入口です。上部の3ボタンで目的を切り替えます。

- 「📱 Nexus Ark Lite」は、本体接続と独立モードの違いを最初に表示します。それぞれのボタンから設定を始めます。
  独立モードの日常操作は「4. お出かけの準備へ進む」から進み、
  「← Liteの使い方・接続設定へ戻る」で設定へ戻れます。日常操作は短い4段階表示の下に、
  今の状態で必要な操作だけが開きます。接続、ペルソナ選択、お出かけ前データの準備、出発、帰宅の
  順序を覚える必要はなく、通常は画面に表示された次のボタンへ進みます。「現在の状態に更新」は
  接続状態とペルソナの現在地を同時に確認し、更新中表示と完了時刻を表示します。
  設定欄へ戻る時は「初回設定・接続管理へ移動」を押すと、同じページの先頭へ移動します。
- 「📤 外部AIへ持ち出す」は、公式チャットアプリ向けのデータを作成します。
- 「🏠 外部AIから帰宅」は、公式チャットアプリの会話ログを現在のルームへ統合します。

本体確認キーや帰宅データ確認キーなどの設定欄はLite独立モードにだけ表示します。
通常の出発・帰宅と、削除・緊急帰還などの保守／復旧操作は同じモード内の別の欄に分かれています。

お出かけ画面では一般向けの名前を先に表示し、技術名は括弧内に記載します。

- **Lite用クラウド（Cloudflare Worker）**: PC停止中にスマホとの接続を受け持つ自分専用の窓口です。
- **お出かけ前データ（snapshot）**: ペルソナの今の状態を暗号化して用意するコピーです。
- **帰宅データ（bundle）**: Liteで増えた会話を署名付きで本体へ戻すデータです。
- **本体では休んでもらう（単一存在 / exclusive）**: 帰宅まで本体側の活動を止める通常の選択です。
- **本体にも残す（並行存在 / parallel）**: 選んだペルソナは、お出かけ中もPCのNexus Arkで会話や自律行動を続けられます。本体での活動にはPCのNexus Arkが起動している必要があります。Liteの独立モードでも会話できます。両方の会話はリアルタイムには同期されず、Liteでの経験は帰宅時に本体へ取り込みます。

一緒に行くペルソナは1〜3人選べます。「本体にも残す」で選ばなかったペルソナは、帰宅まで本体での活動を休みます。帰宅後も、有効なお出かけ前データと接続準備が揃っていれば「現在の状態に更新」で「3. 出発」へ進めます。出発は内容を確認してから行います。

### 接続確認とスマホ登録

初回クラウド準備とAI設定の次に「接続確認とスマホ登録」を開き、「初回設定」「既存接続の確認」「端末を再登録」から目的を選びます。
本体、Lite用クラウド、スマホ、お出かけ前のデータの4状態と、次に押す場所が一つのカードに表示されます。

- 「4状態を確認」はWorkerと端末の状態をこのPCから読み取るだけで、Cloudflare資源やSecretを変更しません。
- 「短期ペアリングコードを発行」は、実際に持ち出すPWAで入力する短期コードを明示的に発行します。
- 「4. お出かけの準備へ進む」は、ペルソナ、AIモデル、持ち出すデータを選ぶ日常画面へ進みます。

PWAの4状態と本体画面の4状態は、別々の端末から確認した結果です。PWAが緑でも、本体画面は起動直後に
外部通信を自動実行しないため、2と3を「このPCでは未確認」と表示します。異常を意味する表示ではありません。
「このPCから4状態を診断」を押すと、このPCに保存した本体確認キーでLite用クラウドとペアリング済み端末を確認します。
診断後に「クラウド更新が必要」と出た場合は、PWAが現行機能へ接続できていても、本体最新版が使う新機能に対して
Workerが古い状態です。4状態カードの直下に「次にすること：Lite用クラウドを更新」が自動表示されます。
閉じた詳細メニューを探す必要はありません。

お出かけ中に本体だけを先に更新し、Lite用クラウドの更新が必要になった場合は、クラウド更新より「4. 帰宅」を先に表示します。
「帰宅する内容を確認」→「確認した内容を本体へ戻す」で現在のお出かけを閉じてから、4状態を確認してLite用クラウドを更新してください。

1. 自動入力された保存領域名を確認し、「2. 安全更新計画を作成」を押す。通常は入力不要です。空欄の場合にCloudflareで確認する値は「Storage & databases」→「D1 SQL Database」の一覧にある **Name**（例: `nexus-ark-lite-relay`）で、UUIDではありません。ここまではクラウドを変更しません。
2. 「3. 作成された更新計画を確認」を開き、対象と復旧方針を確認する。
3. 確認欄へチェックし、「4. 確認した更新計画を実行」を押す。この操作で復旧点取得、必要な保存領域更新、Worker公開、事後診断を順に行います。
4. 成功すると上の4状態も自動更新されます。期限を迎えたデータがある場合は、更新成功後に「削除期限の確認あり」と件数を表示します。これは更新失敗ではありません。

接続不能、認証失敗、schema不整合などで事後診断を完了できない場合は、自動で元へ戻さず復旧点を保持して停止します。
事後診断だけを再確認する場合、完了済みの保存領域更新やWorker公開は繰り返しません。

保存領域名は現在の接続設定から自動入力されます。更新後に古い参照先が残っていても、接続先と一致する生成済み設定が1件だけなら自動で見つけ直します。
空欄のままならD1一覧のNameを確認してください。同じ接続先に一致する設定が複数ある場合は、安全のため自動選択しません。
端末が有効と確認済みなら、この更新のためにPWAを再ペアリングする必要はありません。

更新欄には、Nexus Arkに同梱されたLiteの準備ツールの状態も表示されます。不足や不一致がある場合は
計画作成ボタンが無効になり、「Liteの準備ツール」から署名済み更新を確認できます。個別のツールを導入したり、
場所や版を選択したりする必要はありません。

短期コードを発行すると、同じ場所に「持ち出すPWAへ短期情報を渡す」QRが表示されます。QRに含まれるのは
WorkerのLite HTTPS URL、5分・単回の短期コード、有効期限だけです。OWNER Token、帰宅bundle署名鍵、
provider API key、本体接続用Token、snapshot本文は含まれません。

QRを読むとLiteの接続設定へWorker URLとコードが入ります。短期情報はURLのfragmentとして渡され、Liteが
取り込んだ直後にアドレス欄から消えます。保存先を確認できるよう、ペアリングは自動実行されません。表示中の
画面が実際に持ち出すインストール済みPWAであることを確認してから「ペアリング」を押してください。

端末やOSによっては、QRからインストール済みPWAではなく通常ブラウザが開きます。その場合は通常ブラウザで
ペアリングせず、持ち出すPWAを開いて、ウィザードに表示されたWorker URLと短期コードを手入力してください。
期限切れの場合は本体で新しいコードを発行します。

通常ブラウザとインストール済みPWAは、端末によってTokenなどの保存領域を共有しません。通常タブで
ペアリング済みでも、持ち出すPWAが未ペアリングなら、そのPWA内で短期コードを入力してください。
OWNER Token、帰宅bundle署名鍵、provider API keyはLiteへ渡りません。

基本手順は次の通りです。

1. 「本体接続の設定」を開き、「本体接続を有効にする（API Gateway）」をONにする。
2. PCの電源とNexus Arkを起動したまま使うこと、スマホが同じWi-FiまたはTailscaleへ接続済みであることを確認する。
3. 「Token認証を使う（推奨・通常はON）」をONにし、「Token生成」で接続用Tokenを作る。
   本体URLはスマホから開く住所、Tokenはこの本体へ入るための合言葉です。Tokenを他人へ送ったり、
   公開画面やスクリーンショットへ載せたりしないでください。
4. 「本体接続の設定を保存」を押し、「スマホ用URL・接続情報を更新」を押す。
5. すぐ試す場合は、同じWi-Fi用として自動表示された`192.168...`等のURLを開く。Liteのインストール、
   音声入力、通知も使う場合はTailscale HTTPSを設定し、
   表示されたスマホ用QRコードを読み取る。URLを直接開いても構いません。
6. Liteの「設定」→「接続設定」で本体URLとTokenを確認し、「接続」を押す。画面上部が
   「🏠 本体接続」、メニューが「接続済み」になり、ルーム一覧や会話が表示されれば完了です。
   QRコードにはTokenは含まれません。

普段は、PCでNexus Arkを起動してから同じスマホのLiteを開きます。本体URLとTokenは端末へ保存されるため、
接続先を変えた時やTokenを作り直した時以外は再入力不要です。PCがスリープ・終了すると本体接続も停止します。
HostとPortは通常`0.0.0.0`と`8000`のまま使い、別アプリとの競合や詳しい案内がある場合だけ変更します。

Liteの「設定」→「接続設定」には「この端末へLiteをインストール」が表示されます。Androidや対応ブラウザでは
「この端末へインストール」を押します。iPhone／iPadなどボタンを出せない環境では、表示された案内に従い、
Safariの共有ボタンから「ホーム画面に追加」を選びます。追加後はホーム画面のLiteを開き直してからペアリングします。
通常ブラウザのままペアリングする場合は、そのブラウザを持ち出しに使う確認が必要です。

接続用Tokenと本体URLは、インストール済みPWAの通常保存領域と現在のPWAセッションの両方へ保存します。
再読込時は保存済み情報から自動接続し、チャット履歴を先に復元します。現在地などの補助情報だけが一時的に
取得できない場合も、チャット接続は維持します。画面資源はオンライン時に最新版を確認し、通信できない時だけ
保存済み画面へ戻るため、修正版が古いService Workerのcacheに留まり続けないようにしています。

Nexus Ark Liteは下部の「チャット」「記録」「管理」「設定」で画面を切り替えます。長いメニューを探し回らず、会話、ノート類、外部連携、接続設定へ直接移動できます。
どの画面でも上部に「本体接続」または「独立モード」と、最新の退避データの経過時間が表示されます。
独立モード中の「本体へ戻る」も同じ上部から開けます。

「チャット」「記録」「管理」では接続状態を一行だけ表示します。再接続などが必要な場合も、その一行から
「設定」へ移動できます。詳しい4状態カードと保存領域の説明は「設定」だけに表示されるため、通常画面を広く使えます。

チャットでは送信時刻と使用モデルを確認でき、最新の応答を再生成できます。起動時や応答受信時に入力欄へ勝手にフォーカスせず、過去の会話を読んでいる間は新着ボタンで続きを知らせます。「過去」から古い履歴を追加表示でき、入力途中の文はルームごとに端末へ下書き保存されます。

ペルソナが画像生成ツールで作った画像は、応答本文と一緒にチャットへ表示され、履歴を再取得した後も残ります。
通常の本体接続モードでは、Liteを画面に表示している間、ペルソナの現在地を定期的に確認します。
自律行動や本体画面からペルソナが移動した場合も、画面全体を再読み込みせず現在地表示へ反映されます。
独立モード中は、本体側の現在地を混ぜないためこの定期確認を行いません。

「記録」では研究ノート・創作ノートの閲覧と編集に加え、日記・メモ帳を読み取り専用で確認できます。手紙箱で手紙を開くと本文が表示され、本体側と同期して既読になります。

チャット入力欄の「🎁」から、所持品をペルソナへ贈る、ユーザーが使う、場所へ配置する、拾う、場所のアイテムを使う操作ができます。実行前に変化内容を確認し、実行後はその出来事をチャットへ伝えられます。食べ物を使った場合は、本体と同じ味覚・物理感覚・イメージ情報とアイテム画像がペルソナへ渡ります。

「管理」のTwitter下書き一覧では、添付画像の有無だけでなく画像そのものを確認してから承認・却下できます。画像添付、音声入力、TTS再生、現在地移動、自律行動設定も引き続き利用できます。

### Lite独立お出かけモード

持ち出す量は「おすすめ」「最小限（システムプロンプトのみ）」「自分で選ぶ」から選べます。「おすすめ」には、
システムプロンプト（必須）、コアメモリ、今日を除く直近2日分のエピソード記憶、直近40件の会話が入ります。
「自分で選ぶ」では、エピソード記憶を0〜30日、直近の会話を0〜40件で調整できます。日記記憶はLite snapshotへ入りません。出発前の確認にはペルソナごとの
セクション別文字数と会話件数が表示され、読み取り専用JSONで実際の本文も確認できます。
PWAから待機データを更新する場合も同じ選び方を使えます。ただしPWAから更新できるのは、現在選んでいる
ペルソナ1人だけです。複数のペルソナを連れて行く準備と出発はPCで行います。
エピソード記憶はペルソナごとに50,000文字が上限です。超えた場合は日数を減らすか、含めない設定にしてください。
お出かけ前データの自動更新は新しい端末では既定ONです。本体接続中にLiteを開いた時と、画面を表示している間の
定期確認で、最短6時間・内容変更時にだけ更新します。送信中、同期中、独立モード中には実行しません。
画面上部には最終退避からの経過時間が常に表示され、6時間以上なら更新推奨になります。

待機中のsnapshot本文はWorker側で暗号化されます。独立モードを開始した後の実行用snapshotはD1上の
旅行セッション用データとして保存されるため、CloudflareアカウントとWorkerを自分で管理してください。
自動検査はAPIキーらしい値・秘密鍵・一部の絶対パスを対象にしますが、一般の個人情報すべてを検出するものではありません。

Liteの「設定」→「接続設定」→「別のAIチャットアプリへ持ち出す」では、PCを使えない時も、準備済みの
待機データから選択ペルソナの外部AI用文面を作れます。独立モード開始後は、旅行セッションに保存された
**独立モード開始時点**の内容を使います。人格設定、選択済みの記憶、直近会話を外部AIと端末の
クリップボードへ渡す確認にチェックし、「外部AI用の文面を表示」→内容確認→「文面をコピー」の順に進みます。
本文は明示操作時だけWorker内で復号・整形され、LiteのlocalStorage、sessionStorage、Service Worker cacheへ
保存されません。「画面から消す」または項目を閉じると表示本文を消せます。コピー後は外部AIの最初の
メッセージ欄へ貼り付けてください。外部AIで増えた会話は自動帰宅しません。

「お出かけ」→「📱 Nexus Ark Lite」→「Lite用クラウドを接続・確認（すでに準備済みの方）」は、PCを停止している間も
ユーザー自身のCloudflare WorkerからLiteで会話するための設定です。Phase 5では通常のNexus Ark Liteと
独立お出かけを同じ画面へ統合しました。「設定」では「🏠 本体接続」「🧳 独立モード」で現在の送信先を
確認できます。チャットなどの通常画面は小さな一行表示だけにします。認証、下書き、未確定送信IDは接続先ごとに分離され、自動切替・自動再送はしません。

1回のお出かけにつき最大3ペルソナを扱えます。Worker URL、所有者Token、帰宅bundle署名鍵、
「使用するAIサービス／接続」、最初に使うAIモデル、帰宅後の本文保持期間を入力し、
「独立お出かけ設定を保存」を押します。所有者Tokenと署名鍵は本体ローカル設定へ保存され、
Lite端末には渡りません。

普段のお出かけでは、PCの「お出かけ前の準備」にある「今回使うAI」で、AIサービス／接続とAIモデルを
選び、「今回使うAIを保存」を押します。候補から選ぶほか、利用するモデル名を直接入力できます。
Tokenや署名鍵などの接続設定を開き直す必要はありません。
APIキーを新しく入力し直す必要はありません。「本体に保存済みのAIサービスをLiteでも使えるようにする」で、
通常チャット用に保存済みのキーを利用します。保存済みキーが1件なら自動選択し、複数ある時だけ使う1件を選びます。
すでにLiteで利用可能なAIサービスには再設定を求めません。PC停止中は本体内のキーを読めないため、
初回またはキー変更時だけ、自分のLite用クラウドへ保存する明示確認を行います。
「Lite内部のAI接続ID」と「Cloudflare Secretの保存名」は通常変更不要の詳細設定です。

Gemini、OpenAI、Anthropic、xAI、OpenRouterから普段使っている接続を選べます。
「使用するAIサービス／接続」を選ぶと、本体に保存済みのモデルが
「最初に使うAIモデル（必須）」へ表示されます。必要なら「最新のモデル一覧を取得」を押して更新できます。
一覧に出たモデルを選ぶほか、普段使っている最新のモデル名をその場で直接入力できます。
候補表示だけでは外部通信せず、最新一覧の取得はボタンを押した時だけ行います。

設定画面での候補表示はローカルですが、「お出かけ前データを準備」または実際の出発を確定する直前には、
本体がWorker経由で選択プロファイルの公式モデル一覧をlive更新します。モデルが一覧にない、会話能力を
確認できない、または一覧自体をlive確認できない場合はsnapshot登録を停止し、別モデルの明示選択を促します。
料金の概算表示に未対応のモデルも、そのまま利用できます。その場合は利用額を「金額不明」として記録します。
別モデルへの暗黙の置換は行いません。

「帰宅後、Lite用クラウドに会話本文を残す期間」は、帰宅時にすぐ削除（0日）、帰宅後7日、帰宅後30日から
選びます。帰宅後の復旧用本文に対する設定で、「お出かけ前データ」の保存期間とは別です。

「料金と応答の詳細設定」にある「1回答の最大長」は、通常は空欄のままにします。空欄ではGemini、
OpenAI、xAI、OpenRouterへ固定の短い上限を送らず、選んだモデルに応答長を任せます。API仕様上指定が
必須のAnthropicだけは、通常の会話を途中で切りにくい十分な内部上限を使います。特別に長さを抑えたい
場合だけ、1〜65,536 tokensの上限を入力できます。旧版の初期値2,048は自動設定へ移行します。

同じ詳細設定では、日次上限、1回のお出かけ上限、警告率、日次境界のタイムゾーン、キャッシュ方針も
設定できます。料金を確認できないモデルも利用でき、その分は「金額不明」として残ります。上限到達時は
通信切断とは区別して「回答が選択中のモデルの最大長に達しました」と表示します。

Phase 4では中央「外部接続」→「Lite・お出かけ」→「📱 Nexus Ark Lite」から独立モードを開き、1〜3ペルソナを選び、対象ごとに
「本体では休んでもらう（単一存在 / `exclusive`）」または「本体にも残す（並行存在 / `parallel`）」を指定します。travel版Liteでは
ペルソナを切り替えると履歴、経路、予算、利用額、存在状態が一括で切り替わります。別ペルソナを選んでも、
同じ旅行セッションで同時に実行できる生成要求は1件です。

Phase 5では、あらかじめ「選んだペルソナの『お出かけ前データ』を準備」を押すと、存在ロックや会話を開始せずに
世代付きsnapshotをWorkerへ準備できます。本文はWorker側で暗号化され、Liteへ返るのは作成日時、期限、
世代、ペルソナ、hashなどのmanifestだけです。既定保持は7日、上限30日で、24時間を超えたsnapshotは
古い可能性を表示します。

既定は手動更新です。接続設定で「本体接続中のLite起動時にも更新」を明示的にONにした端末だけ、
起動時にも更新を試みます。本体接続中で、前回成功から6時間以上経過し、持ち出し内容が変わった場合だけ
新世代を登録します。条件を満たさない場合や更新に失敗した場合も、直前のready世代は維持されます。

PCへ接続できなくなった場合は同じLiteを開き、「独立モード」を押します。Liteは開始前に本体を再確認し、
到達不能なら「本体状態未確認の分岐開始」であることを表示します。確認後だけ
`recovery_unconfirmed`として開始し、常にhome／travelの分岐可能性を記録します。本体復旧を検出しても
自動帰宅しません。「本体へ戻る」で未確定送信を確認し、署名付き差分の取込とack／closeが完了した後だけ
本体接続へ戻ります。インターネットも利用できない場合は下書きだけが保存され、AI応答は生成されません。
ブラウザの通常タブとインストール済みPWAは端末によって保存領域が分かれるため、実際に持ち出すPWA内で
ペアリングしてください。継続中の独立セッションがある場合、PWAを閉じて開き直してもWorkerから復元され、
本体へ自動切替しません。「本体へ戻る」は押した時点で本体への到達性を再確認します。

独立モードのチャット先頭には、「お出かけ前から引き継いだ直近の会話」として持ち出したユーザー／AIメッセージを表示します。
この区切りより後ろが外出中の新しい会話です。引き継ぎ済みメッセージはAIの文脈にも使われるため、
例えば「お出かけ前の直近メッセージを一言で説明して」と尋ねて引き継ぎを確認できます。
ただし、AIの要約表現だけでなく、画面上の元メッセージ表示も確認してください。

Liteの「設定」にある「接続状態」には、「本体」「Lite用クラウド」「端末」「お出かけ前のデータ」を別々に表示し、それぞれの
次の操作を示します。通常ブラウザで開いているか、インストール済みPWAで開いているかも同じカードで確認できます。
端末認証の期限切れや本体側での端末失効を検出した場合は「待機snapshotなし」ではなく
「再ペアリングが必要」と表示します。本体で新しい短期ペアリングコードを発行し、実際に持ち出すPWA内で
入力してください。Workerへ一時的に接続できない場合は再ペアリングが必要とは断定せず、通信の再確認を案内します。
ペアリングが完了すると、操作ボタンは「ペアリング済み」に変わり、状態カードの「端末」もペアリング済みと表示されます。

Lite用クラウドの更新直後にPWAだけが古い場合は「PWA更新が必要」と表示します。この場合、端末認証は
失効していないため再ペアリングせず、「PWAを更新して再読み込み」を押してください。端末情報が保存済みの状態で
短期コードを再入力しても登録台数を増やさず、同じ端末の資格情報を安全に更新します。
Workerのページ自体を通常ブラウザで開けるのにPWA内通信だけ失敗する場合は、本文を読まない追加疎通で
回線断と接続元URLの未許可を区別します。未許可の場合は「現在のPWA」に実際の接続元を表示するため、
本体側の許可URLと比較してください。通常通信と追加疎通の両方が失敗した場合は、接続状態の詳細に
「共有用診断」が表示されます。そこにはUI版、実際のPWA／Worker origin、ブラウザのオンライン判定、
安全な接続かどうか、HTTP状態、応答形式、API schema、短く整形したブラウザ例外だけが含まれます。トップ画面と
接続モジュールは同じ版を読み込み、オンライン時はHTTP cacheを使わず最新版を確認します。版が揃わない配布物は
公開前検査で停止するため、更新後に一部だけ旧cacheへ残ることも防ぎます。Token、ペアリングコード、snapshot本文は
診断表示に含めないため、表示された一行をそのままサポートへ伝えられます。

「Lite用クラウド」が「接続済み・削除期限の確認あり」の場合、接続障害ではありません。削除期限を迎えた
帰宅後データ／お出かけ前データの件数がカードに表示されます。この状態でもスマホの状態を続けて確認するため、
有効な端末があれば「有効（N台）」と表示されます。診断後はカード直下に削除確認が現れます。
「期限切れ本文を削除して状態を更新」を押した場合だけ既存の保持期限処理を実行し、続けて4状態を再診断します。
「今は削除しない」を選べば本文はそのまま残り、状態確認だけで自動削除されることはありません。
中央「外部接続」→「Lite・お出かけ」→「📱 Nexus Ark Lite」から開く独立モードの日常操作欄では削除操作を複製せず、
接続可能であることを示したまま「初回設定・接続管理へ移動」で同じページの確認欄へ移動します。

同じ設定欄の「詳細・保守（問題がある時だけ）」では、Liteの準備ツール、relay同梱資源、Worker／D1 schema、
必須Secret、進行中旅行を診断できます。安全更新はTime Travel bookmarkを先に記録し、migration、deploy、
事後診断の順で実行します。失敗時にD1を自動restoreしません。端末一覧、全端末失効、保持期限preview／
手動掃除もここから実行できます。

帰宅は本体の「帰宅する内容を確認」で分岐と未取込件数を確認します。確認に成功した時だけ
「確認した内容を本体へ戻す」が押せるようになり、
ペルソナ別の署名付き差分を取得します。ローカル確定後のackと全員ack後のcloseにより途中再開できます。
Workerへ接続できない場合は署名付きbundle v4をファイル復旧経路として使えます。`parallel`と緊急帰還の
home／travelログはSYSTEM境界付きの別区間として保存され、自動で意味統合されません。最終経路の本体反映は
「最終モデル設定の反映提案（既定OFF）」で選んだ対象だけに適用され、通常モデルやSecretは自動変更されません。

手動fallbackでAPIキーを登録する場合は、先に`cloud/lite-relay/wrangler.phase2.example.jsonc`を実運用用の
追跡対象外ファイルへコピーし、D1とKVのIDを照合します。画面の「Cloudflare SecretへAPIキーを
1件登録」でプロバイダ、本体に保存済みのキー、固定allowlistのbinding、資格情報プロファイルID、
Lite表示名を選び、送信先と保存先の確認にチェックしてから登録します。同梱されたLiteの準備ツールと
Cloudflareへのログインが必要です。

登録操作は選択した1件だけをWranglerの標準入力からCloudflare Secretへ送り、続いてWorkerへ
Secret値を含まない資格情報プロファイルを登録します。値は画面、設定保存結果、ログ、D1、KV、
Lite応答へ出しません。不要になったキーは、画面に記載された`wrangler secret delete <binding名>`を
同じ設定ファイルで実行して削除してください。

Workerの配置、D1 migration、KV、`OWNER_AUTH_TOKEN`、`BUNDLE_SIGNING_KEY`の登録前には、
[Lite用クラウドの準備ガイド](07a_lite_cloud_setup.md)で対象資源と安全条件を確認してください。
Tokenや署名鍵を画面共有・ログ・URLへ貼らないでください。

Phase 2対応Workerとtravel版Liteでは、Gemini、OpenAI、Anthropic、xAI、OpenRouterの資格情報
プロファイルを選び、プロファイルごとの公式モデル一覧を更新して会話途中に経路を切り替えられます。
切替は確認操作後にだけ確定し、会話へ経路変更マーカーが残ります。確定済みテキスト履歴以外の
プロバイダ固有状態は引き継がれず、別モデル／別プロバイダへの自動fallbackも行いません。

統合版Liteでは、独立モード中だけチャット上部に「今回使うAI」が表示されます。通常は現在のAIサービスと
モデルだけをコンパクトに表示し、開くと選択中ペルソナの利用額と予算状態も確認できます。AIサービス／接続や
モデルを選んだだけでは変更されず、「このAIへ変更」の確認後にだけ反映されます。送信中は切替できず、切替中は送信や
ペルソナ切替ができません。モデル一覧の取得や変更に失敗しても現在のAIを維持し、自動再送しません。
応答長が自動の場合は変更先のモデルにも固定の短い上限を引き継がず、そのモデルの通常の長さで応答します。
Liteで使えないのは本体の長期記憶更新やPC内ツールなど本体依存機能であり、応答本文を意図的に短縮するものでは
ありません。

Phase 3対応Workerでは、travel版Liteに今回／今日の既知利用額、金額不明件数、保留中の予約上限、
キャッシュ読込／作成量を表示します。警告率到達時は注意を表示し、上限超過見込みは生成APIへ送る前に
停止します。Gemini明示キャッシュを選んだ場合、キャッシュ名はWorker内部だけで管理され、帰宅close
または本文即時削除時に削除されます。

モデル一覧の短時間cacheはKVへ置きますが、Secret値、binding ID、Authorization headerはLite、
D1本文、KVへ返しません。帰宅bundle v2は初期／最終経路、各eventのroute epoch、要求／解決モデル、
gateway、取得できた上流を署名対象に含め、本体が相互の一致を検証してから取り込みます。

## 安全診断

「Lite・お出かけ」→「📱 Nexus Ark Lite」→「安全診断」では、Host、Port、Token認証、レート制限、監査ログ、Tailscale HTTPS候補などを確認できます。
公開HostでToken認証なしにする設定は安全側で拒否されます。

インターネットへ直接公開する運用は推奨しません。
同一LANやTailscaleなど、本人が管理できる範囲で使ってください。

## 外部イベント

「外部接続」→「API・外部ツール」→「外部イベントテスター」では、外部イベントを現在のルームへ記録できます。
自作アプリや通知システムから、状態変化やイベントをペルソナへ渡したい場合の確認に使います。

## API能力一覧

「外部接続」→「API・外部ツール」→「利用可能なAPI一覧・外部連携リファレンス」には、現在実装されている全APIと利用条件が自動表示されます。同じページの「外部ツール連携について（詳しい方向け）」には、APIを自作ツールから使う際の説明があります。「安全」はアトリエアプリから追加承認なし、「要承認」は表示された権限をアプリごとに許可した後、「所有者Token限定」は本人の接続用Tokenだけで利用できます。

一覧の `{room_id}` は、APIを使う際に対象ルーム名へ置き換えるためのテンプレート表記です。正本カタログは全ルーム共通なので、UI上では特定のルーム名に固定せず `{room_id}` のまま表示します。

自作アプリからは `GET /api/v1/rooms/{room_id}/capabilities` を呼ぶと、同じ一覧をJSONで取得できます。ペルソナがアプリ案を考える際の能力確認にもこの一覧が表示されるため、実装済みAPIを確認してからアプリへ組み込めます。
