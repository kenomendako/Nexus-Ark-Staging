# PCを止めてLiteを使うための準備ガイド

## 目的の操作へ進む

中央の「外部接続」→「Lite・お出かけ」を開きます。

| 今回の目的 | 押すボタン |
|---|---|
| 初めて設定する | 「初回設定・接続管理」→「PCを止めても使う」 |
| 2回目以降のお出かけ | 「お出かけを準備」 |
| お出かけから帰宅する・中断した帰宅を再開する | 「帰宅・統合」 |
| スマホ登録・接続確認・クラウド更新 | 「初回設定・接続管理」→「4状態を確認」 |
| PCを起動したまま本体につなぐ | 「初回設定・接続管理」→「PCをつけたまま使う」 |

設定済みなら「📱 Nexus Ark Lite」も日常画面へ直接進みます。出発中は帰宅の操作が優先されます。
**初回設定やCloudflareへの認証を毎回やり直す必要はありません。**
「アカウントの追加・切替: この画面では未実行」は、この画面で認証し直していないという意味で、保存済み接続の消失ではありません。

## 初回だけ行う設定

必要なものは、対応するWindows x64版Nexus Ark、自分で管理するCloudflareアカウント、普段使うAIサービスのAPIキーです。
スマホへAIサービスのAPIキーや本体確認キーを入力する必要はありません。

### 旧版から更新したときの起動方式確認

更新後に「新しい更新方式へ移行」が自動表示されるわけではありません。通常会話はそのまま確認できます。Lite独立モードを準備する前に、中央「外部接続」→「Lite・お出かけ」→「初回設定・接続管理」→「PCを止めても使う」→「PCを止めても使うための初回設定」→「Liteの準備ツール」で「状態を確認」を押してください。この確認だけではCloudflareや記憶を変更しません。

- 「新しい更新方式への移行が必要」と表示された場合だけ、「次の手順を確認」→「新しい更新方式へ移行」を押します。準備完了の表示を確認してからNexus Arkを通常どおり終了し、数秒待って同じ Start.bat で起動してください。再度「状態を確認」を押します。
- 「初回導入が必要」と表示された場合は、起動方式の移行は不要です。案内された署名済み準備ツールの導入へ進みます。
- 「準備済み」と表示された場合は、この移行操作は不要です。

期待した表示にならない場合や更新エラーが出た場合は、同じ更新を繰り返したり手動でフォルダーを上書きしたりせず、現在の版と画面の文言を確認してください。

### 1. Liteの準備とクラウド接続

「PCを止めても使う」を押し、表示されたボタンでこのPCの接続準備を確認します。
「Liteの準備ツール」の「状態を確認」を押し、表示された場合だけ次の操作を行います。

- **準備済み**: アカウントの選択へ進みます。
- **初回導入が必要**: 「次の手順を確認」から署名済みの準備ツールを導入します。
- **新しい更新方式への移行が必要**: 「次の手順を確認」→「新しい更新方式へ移行」を押します。画面の案内に従って更新・再起動が終わったら、「状態を確認」で確認します。通常は完全パッケージをダウンロードする必要はありません。
- **修復が必要**: 「次の手順を確認」から案内された署名済み更新を行います。runtimeの手動コピーや上書き展開は不要です。

#### Cloudflareアカウントを選ぶ

表示中のアカウントを使う場合は、表示名を確認して「このアカウントで続ける」を押します。
これは既存アカウントの選択であり、表示名で新しいアカウントを作る操作ではありません。

別のアカウントを使う・新しく作る場合は、接続許可にチェックし「別の／新しいアカウントで接続」を押します。
Cloudflare公式画面で対象のアカウントへログインし、許可内容を確認して「Authorize」を押します。
認証完了画面になったらその画面を閉じてNexus Arkへ戻れます。本体側の案内に従って上の準備確認を行い、利用するアカウントを確定します。

#### Lite用クラウドを準備する

「新しいLite用クラウドの作成内容を確認」を押します。この確認だけではCloudflareを変更しません。
既存クラウドを接続する場合は、表示された「準備済みのLite用クラウドを接続」を使い、新しく作り直さないでください。

Cloudflareの公開先名は、公式Dashboardの **Build → Compute → Workers & Pages** を開き、
右側の **Account details → Subdomain** で確認します。

- すでに `my-subdomain.workers.dev` と表示されていれば登録済みです。
- その値を「Cloudflareに表示されたSubdomain（必須）」へ入力します。`my-subdomain` の部分だけでも入力できます。
- 未登録の場合だけ、Cloudflare側のSubdomainの登録操作を行います。Nexus Arkの公開名を推測する必要はありません。

作成内容・料金の可能性・中断時の扱いを読み、確認欄にチェックして「確認した計画で準備を開始」を押します。
非公開の準備が終わったら、表示された公開URLを確認し、公開への同意にチェックして
「Lite用クラウドを公開して接続を確認」を押します。準備と公開は別々の確認です。

完了後、必要なURLとキーはこのPCへ自動保存されます。次は同じ画面の「2. AIサービスとモデルを選ぶ」へ進みます。
Cloudflareへの公開だけで、AI会話や独立モードが自動で始まることはありません。

### 2. AIサービスとモデルを選ぶ

本体に保存済みのAIサービス・APIキーから1件を選び、クラウドへ保存する確認欄にチェックして、
表示されたAIサービスの登録ボタンを押します。利用済みなら登録し直す必要はありません。

「使用するAIサービス／接続」と「最初に使うAIモデル（必須）」を確認し、
**「AIと独立お出かけ設定を保存」**を押します。
モデルは一覧選択のほか、名前を直接入力できます。通常の応答長はモデルに任せ、料金不明のモデルも利用できます。
料金表示は推定であり、不明分を無料として扱うものではありません。

URL、確認キー、内部設定ファイルは「Lite用クラウドの接続情報（通常は変更不要）」にあります。
通常は自動保存された値のままにしてください。

### 3. 接続確認とスマホ登録

下の「接続確認とスマホ登録」を開き、「初回設定」を選んで「4状態を確認」を押します。
本体・Lite用クラウドが準備できたら、「短期ペアリングコードを発行」へ進みます。

**すでにスマホへLiteを入れている場合**

ホーム画面から、実際に持ち出すLiteを開きます。その設定画面へWorker URLと短期コードを入力して登録します。
QRを読むと別のブラウザが開くことがあります。別のLiteをインストールし直す必要はありません。

**初めてスマホへ入れる場合**

QRからLiteを開いてインストールし、ホーム画面のアイコンから開き直して登録します。
短期コードの期限が切れたら、PCで再発行します。
通常ブラウザとインストール済みPWAでは、認証情報が共有されない場合があります。

QRが渡すのはWorker URLと短期コードだけです。本体接続のURL・Tokenは移しません。
スマホからPC本体へ直接接続する場合は、その本体接続も別途設定してください。
スマホが本体へつながっていなくても、お出かけ前データはPC側で準備できます。

端末がペアリング済みになったら、本体で「4状態を確認」し、**「4. お出かけの準備へ進む」**を押します。
この時点で「4. お出かけ前のデータ」が未準備でも、次の画面で用意できます。

## 2回目以降：お出かけを準備する

「お出かけを準備」を押します。初回設定画面をたどり直す必要はありません。

1. 「2. お出かけ前の準備」で一緒に行くペルソナ（1〜3人）を確認します。最後に準備した選択がある場合は復元されます。
2. 「今回使うAI」を変更する場合は、AIサービスとモデルを選んで「今回使うAIを保存」を押します。
3. 必要なら「持ち出す情報を選ぶ」で情報量を変更します。
4. 「1. Lite用クラウドへ送る内容を確認」を押し、内容を読んで「2. 確認した内容をLite用クラウドへ準備」を押します。
5. 下の「3. 出発」で「選んだペルソナの出発内容を作る」を押し、確認後に「表示内容を確認して出発する」を押します。

すでに有効な準備データがあり、内容を変えない場合は「3. 出発」へ進めます。
準備済みでもペルソナ・AI・情報量の選択欄は表示されます。編集すると古い確認は無効になり、内容を確認し直してから進みます。
出発は自動では行いません。スマホ側でも、独立モードを開始する確認が必要です。

出発時に通信が切れて「出発結果の確認待ち（本体停止）」になった場合は、出発を繰り返さず、
通信回復後に「帰宅する内容を確認」へ進みます。接続管理の画面からは「帰宅・統合へ進む」で戻れます。
結果が確認できるまで対象ペルソナの本体側の停止を保ちます（「本体にも残す」を選んだ人を除きます）。

「本体にも残す（詳しい設定）」で選んだペルソナは、PC起動中は本体でも活動できます。
本体とLiteの会話はリアルタイム同期ではなく、Liteでの経験は帰宅時に取り込みます。
選ばなかったペルソナは、帰宅まで本体での活動を休みます。

## 帰宅する・中断した帰宅を再開する

PC本体の「帰宅・統合」を押し、「帰宅する内容を確認」→「確認した内容を本体へ戻す」の順に進みます。
「状態・帰宅を確認するペルソナ」で帰宅する人を選べます。本体のチャット選択は変わりません。
同じお出かけの人はまとめて帰宅します。複数のお出かけがある場合は対象を確認して選んでください。
出発中は、クラウド更新が必要でも帰宅の操作を先に案内します。

操作結果には成功件数や失敗理由が残ります。単なる「状態を更新しました」と、帰宅・統合の成功は別です。
失敗した場合は理由を確認して、帰宅内容の確認から再試行します。作り直しやクラウド資源の削除はしないでください。
完了後は現在状態が「帰宅済み」になったことも確認します。

## 接続・更新だけ確認して終了する

「初回設定・接続管理」で「既存接続の確認」を選び、「4状態を確認」を押します。
クラウド更新が必要なら、このカード直下の手順で更新計画を確認・実行します。

「更新する保存領域」が空欄の場合、Cloudflare DashboardのStorage & databases → D1 SQL Database
（画面によってD1 SQLite Database）の一覧で、対象の **Name** を確認します。UUIDではありません。
対象が分からない場合は推測で更新せず、接続先を確認してください。

更新完了後に4状態を確認できれば、更新確認だけならここで終了できます。
ペアリング、データ準備、出発を毎回やり直す必要はありません。

対応版へのクラウド更新時には、長時間「処理中」のまま残った送信を回収する定期処理も追加します。
既存の接続先や保持期限の設定は引き継ぎます。更新を反映するまでは、この回収機能は有効になりません。

## 中断・エラー時

- **公開URLが一致しない**: 公開済みの可能性があるため、準備や公開を繰り返さず、保存された操作記録と接続先を確認します。照合できるまでは停止したままです。
- **準備や公開の途中**: 結果が分からないまま連打せず、再起動後に初回設定の準備確認から状態を読み直します。操作記録が一致する場合は完了済み部分を作り直さず再開します。
- **候補のアカウントがない**: 再認証を繰り返したり、違うアカウントを推測で選んだりしません。画面に復旧欄が出た場合だけ公式Dashboardの表示名・account ID・資源の有無を照合して進めます。
- **保存領域や公開先が一部だけ見つかった**: 自動で作り足さず停止します。接続先や操作記録の案内を確認します。
- **スマホが未ペアリング**: 実際に持ち出すPWAを開き、新しい短期コードで登録します。
- **スマホに再ペアリングが必要と出た**: 本体で新しい短期ペアリングコードを発行し、スマホの登録欄へ入力します。入力したコードを使う登録ボタンから続けられます。
- **確認キーを失った**: 新しい値を推測で作らず、復旧案内に従います。
- **新規準備は安全停止中**: その版では初回準備を実行できません。ファイルを書き換えず、対応した署名済み更新を待ちます。

## 限定ベータの利用条件と安全

- 対応環境は署名済みLite専用runtimeを含むWindows x64です。Windows arm64、macOS、Linuxでの初回準備は対象外です。
- CloudflareのWorker・D1・KVは、自分のアカウント内に作成されます。他の参加者との共用ではありません。
- CloudflareとAIサービスは、契約・利用量によって料金が発生する場合があります。料金表示は請求確定額ではありません。
- 帰宅後の会話本文とお出かけ前データの既定保持は7日です。画面で選んだ期間と期限後の削除確認が優先されます。
- 初回の準備・公開・AIキー登録・スマホ登録・出発・帰宅は、それぞれ明示的な操作で進みます。
- 本体確認キー・帰宅データ確認キー・AIのAPIキーをスマホ、チャット、画面共有へ貼らないでください。
- 中断しただけでは、作成済み資源を自動削除・復元しません。削除や復旧は別の確認が必要です。

公式情報: [Cloudflare Dashboard](https://dash.cloudflare.com/)、
[Workers料金](https://developers.cloudflare.com/workers/platform/pricing/)、
[D1料金](https://developers.cloudflare.com/d1/platform/pricing/)、
[Workers KV料金](https://developers.cloudflare.com/kv/platform/pricing/)。

### 手動運用する詳しい方へ

一般ユーザーはコマンド入力不要です。手動運用する場合のみ `cloud/lite-relay/README.md` と
`wrangler.phase2.example.jsonc` を参照し、実運用設定・binding・schema・必須Secretを照合してください。
例を直接編集せず、dry-run、未公開version、明示公開、公開後診断の順を守ります。
Secretをコマンド引数、通常ファイル、ログへ残さず、資源削除・復元・料金プラン変更を初回準備と混同しないでください。
